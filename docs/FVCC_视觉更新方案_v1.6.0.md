## 二、配色方向（两案择一）

- **方向 A「精修冷灰」**（推荐，演进式）：保留现有蓝主色，中性色阶重排（暗色卡片提亮一档、边框降一档拉开层次），语义色（完成绿/错误红/暂停灰蓝/进行中蓝）统一饱和度带，主按钮降一档明度去刺眼。改动集中在 `style.css` 的 `--c-*` 变量，风险最小。
- **方向 B「fnOS 原生感」**（革命式）：向 fnOS 系统控件视觉靠拢（更大圆角、浅色填充底、系统蓝），观感提升更大但与 DESIGN.md 现有 Named Rules 冲突面大，需先修订契约。

## 三、实施批次（每批独立可验收）

1. **批次①令牌层**：按选定方向重调 `style.css` 明暗两套变量 + `tailwind.config.js` 映射；`check:design --all` 全绿。
2. **批次②控件层**：`ui.ts` 新增自绘 `selectField / checkbox / button(variant: primary|ghost|danger-ghost)`，替换 V2/V4 落点；R6 对话框无障碍沿用。
3. **批次③外壳**：导航分组标签样式化 + 补全图标（V3）、搜索胶囊重排、状态栏徽标化（节点 0/2 在线、队列 n）。
4. **批次④逐页**：V1 趋势图修复（轴留白/裁切/空日压缩）→ V5 任务分区与空状态 → V6 编辑器左栏（根下拉显示全路径尾段+tooltip、按钮加宽、走带 hover 态）→ V7 服务器卡片栅格+空态 → V8 内联样式清零。
5. **批次⑤微交互**：页面切换/列表项过渡（遵守 R5 禁 max-height 动画）、骨架屏统一、toast 时长与层级规范。
6. **批次⑥ FVCS Fyne GUI 复活（路线 A）**：`build.ps1` 增 `-Target FVCS-UI`（CGO/mingw 已具备）编译 `cmd/ui` + `cmd/settings` 出 `fvcs-ui.exe` / `fvcs-settings.exe`；界面按 Fyne 主题色贴近 FVCC 蓝调、图标沿用现有内嵌资源；发布说明补「渲染节点托盘」章节。FVCS 版本 1.2.6→1.3.0（GUI 纳入发布即功能版）。
